# Customer Demographic Analysis

## 1. Project Objective
To analyze customer tour enquiries and identify
popular travel destinations, customer age groups,
and annual income brackets.

## 2. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## 3. Dataset
The project uses a sample dataset containing
1500 unique customer enquiry records.

## 4. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Corrected numeric data types.
- Prepared data for analysis.

## 5. Exploratory Data Analysis
- Analyzed popular travel destinations.
- Grouped customers by age.
- Categorized customers by annual income.
- Calculated average age and income.

## 6. Key Findings
- Goa: 280 enquiries
- Manali: 239 enquiries
- Kerala: 200 enquiries
- Jaipur: 155 enquiries
- Mumbai: 121 enquiries

## 7. Data Visualization
Created four visualizations:
- Popular Destinations Bar Chart
- Customer Age Histogram
- Age Group Bar Chart
- Income Bracket Bar Chart

## 8. Conclusion
The project demonstrates data cleaning,
exploratory data analysis, demographic grouping,
and visualization using Python.

## 9. Dataset Limitation
The dataset is synthetically generated for
practice because the original company dataset
was not provided.
The findings should not be treated as actual
Growfinix customer insights.
